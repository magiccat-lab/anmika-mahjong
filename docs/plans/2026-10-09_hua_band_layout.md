ラフ 3 案から c (上の空きに 3 人の華を並べる) を選び「良いけど配置とかUIはもっと最適化して。オンドリで散々改善したし活かしてよー。
空白になってる緑だけの領域が無駄だから、そこを活かしてほしい」。

## 2. 決まり (style bible)

オンドリ (apps/dream-order/docs/game-ui、skill game-ui の layout.md) で効いた物をそのまま使う。

- 読む物と押す物を分ける: 華 ・ 点 ・ 河は読む物 = 上〜中央。押す物 (リーチ ・ 鳴き ・ ツモ切り ・ スタンプ) は今の右下のまま動かさない
- 同時に比べる物を隣に: 3 人の華を 1 本の帯に横並び。左 = 上家、真ん中 = 自分、右 = 下家 (席の左右と同じ)。華の数を比べる時に視線が往復しない
- 牌の段は 4 つ。手牌 > 自分の華 [手牌の 0.7] > 相手の華 [自分の 0.77] > 北 [華の 0.75] > 伏せ牌。
  [改訂 10-09: 当初は「相手の華 = 河」だったが、PC で河を 71px に上げたので華とは別の大きさの体系にした。codex の指摘]
- 字の段は 11 / 12 / 14 / 16 / 22px (3 版目と同じ)。11px 未満を作らない
- 強調は 1 つだけ: 自分の華の札は金の枠。丸 ・ 線 ・ 矢印 ・ 常設の説明枠は使わない
- 華の効果は牌の下に字で (春 祝儀 華×1 / 夏 打点 +1 段 / 秋 ドラ +1 枚 / 冬 アリス、2 枚なら 華×2 / +2 段 / +2 枚 / チューリップ)。ルール表 2-2 の言葉に合わせる
- 押す所は 24px (AA) 以上 [オンドリの decisions/2026-09-15-touch-targets-aa.md と同じ。44px は狙わない]。華の帯は押す物を置かない
- 色は app.css の札 ・ 金 ・ フェルトの変数だけ使う。新しい色を足さない

## 3. 合格の線 (作る前に決める)

- 華の牌: PC 自分 52px 以上 ・ 相手 40px 以上、スマホ横 自分 28px 以上 ・ 相手 24px 以上、スマホ縦は今より大きく
- 空き: PC 35% 以下 ・ 一番大きい空き 6% 以下。スマホ横 30% 以下。スマホ縦は今より悪くしない
- 河 ・ 手牌は今より小さくしない。11px 未満の字は 0
  [改訂 10-09: スマホ横の河は 29 → 27px を許す。自分の札にも効果の字を出すと上の行が 17px 高くなるため]
- 押す物が帯や他の物の下に隠れない (オンドリの「覆われた操作 0」)
- 一人回しとオンライン、どちらも同じ卓で崩れない

## 4. 結果 (10-09、同じ山 seed 7 を 30 打牌まで CPU に打たせて計測。今 = 本番 f19a1a8)

| | 空き (今 → 後) | 一番大きい空き | 華の牌 (自分 / 相手) | 河 | 手牌 | 11px 未満 |
|---|---|---|---|---|---|---|
| PC 1440x900 | 55% → 45% | 13% → 8% | 25 → 56 / 43px | 62 → 71px | 74 → 80px | 0 |
| スマホ横 844x390 | 32% → 24% | 8% → 6% | 19 → 28 / 24px | 29 → 27px | 43px | 0 |
| スマホ縦 390x844 | 11% → 10% | 5% → 4% | 自分は数だけ / 21 → 34 / 26px | 35px | 59px | 0 |

- 華が多い時 (自分 八華 + 北 4、上家 4 枚): はみ出し 0。帯が 2 段になり、河は PC 65px ・ スマホ横 22px ・ 縦 29px まで小さくなる
- 届いていない線: PC の空き 35% (後 45%) と一番大きい空き 6% (後 8%)。3 人麻雀で向かいの席が無い分と、河が伸びる分の空き。空きを飾りで埋めることはしない
- 手牌の上限を 86px にするとツモ後の 14 枚が手牌の帯からはみ出したので 80px にした (オンラインの 3 人の通しで見つけた)
- codex の見直し (secretary repo tmp/hua-review-out/review.md) の 9 項目: 1 自分の効果の字 ・ 2 牌の段 ・ 3 3 人を 1 本に ・ 5 縦の圧縮 ・ 6 多い時と長い名前 ・ 9 季節の字 は直した。
  4 PC の空きは席の札を河の横に戻すまで。7 は字 0 件、押す所は 24px の線に改訂。8 スマホ横の和了の字の重なりは前からある物で今回は触らない
