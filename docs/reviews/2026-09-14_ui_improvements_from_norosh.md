## 1. 牌譜の公開 URL ← 最優先

### 現状

`src/lib/ReplayPanel.svelte:40` が `/api/matches` を叩いて **401 なら「Discord ログインすると見れる」**で終わる。
一覧 → 選択 → 再生の 3 手で、URL は 1 本きり。局面を指して人に渡せない。

### 向こう

- `/replay` [一覧] と `/replay/:gameId` [個別] がルーティングにある
- 一覧は `GET /api/replay?page=&limit=` で**認証なし**。2026-09-13 時点で 6,389 局が誰でも取れる
- 一覧 UI に「名前で絞り込み」「検索」がある
- 個別は局・アクション・席・開閉まで URL に載る

### 提案

1. `GET /api/matches/:id/paifu` に**公開フラグ**を足す [対局ごとに「公開する」を選べる形が安全]
2. 公開された対局だけ `/replay/:matchId` で認証なしに開けるようにする
3. `?round=&step=&seat=` を URL に載せて、`ReplayPanel` の `roundIdx` / `stepIdx` と双方向に同期する
4. 一覧に名前の絞り込みを足す [今は `starredOnly` だけ]

全対局をいきなり公開にはしない。**既定は非公開**で、部屋主が出すものだけ公開にする。

## 2. ミュート ← 一番安い

`src/lib/SaiKoroModal.svelte:50` でサイコロの太鼓を鳴らすが、**止める UI が無い**。
向こうには「ミュート」がある。`localStorage` に 1 個フラグを置いて、
`SaiKoroModal` と他の効果音の入口で見るだけでよい。

## 3. 対局中の「山を見る」

`src/lib/WallPanel.svelte:3` のコメントが「山構成 panel [debug 用]」。
向こうは「山を見る / 山を閉じる」がプレイ中の常設ボタンで、
王牌とドラ表示・出目履歴を同じ画面で見られる。

検討や牌譜読みではここが効くので、**牌譜再生と観戦では常時開けてよい**。
対局中の自分の卓で開けるかは裁定が要る [情報量が変わるので]。

## 4. 説明書

向こうは「説明書」「更新履歴」「利用規約」を常設している。
うちは `data/notes/anmika_rules.md` があるが画面から読めない。
ルールが特殊なので、**初見が最初に開く場所**が要る。
既存の md をそのまま表示するだけでも効果がある。

## 5. 色彩調整 [色覚多様性]

向こうは「色彩調整」「緑字」を持っている。
うちは **ぽっちの 4 色 [青・赤・緑・黄] が色だけで区別されている**のが一番きつい。
赤ドラ・金ドラも色頼り。`src/lib/Tile.svelte` は SVG を描いているので、
色に加えて**記号か縁取りを足す**のが素直。

## 6. 操作の省力化

向こうにあってうちに無いもの:

- 自動和了 [和了れる時に自動でツモ / ロン]
- 自動抜き・自動花牌北抜き
- 鳴き無し [ポン・カンの確認を出さない]
- ダブルタップで牌選択 [スマホ]

うちは**右クリックツモ切りと右クリックで見送りは既にある** [`App.svelte:1781-1784`]。
自動系はフィーバーや春の絡みがあるので、**「抜きだけ自動」から入るのが安全**。

## 7. ルールセットの名前付き保存

向こうは人数・赤金・7 牌の枚数・ぽっち色・金北枚数・各祝儀・サイコロ 39 種の単価・
フィーバー中の重複まで編集して、名前を付けて保存できる。
うちは裁定を実装に焼いてある。

**すぐには要らない。** ただし牌譜を公開するなら、
**牌譜に ruleSet とルール版数を保存する**のだけは先にやる価値がある。
後からルールを変えた時に、古い牌譜がどのルールで打たれたか分からなくなる。

## 8. その他

- 牌譜一覧に「名前で絞り込み」
- 切断席の表示 [向こうにある。うちは観戦があるので相対的に弱い]
- スマホの横向き案内。うちも `App.svelte` に横向きの話はあるが、向こうは
  「端末を横にしてください」「この画面は横向き（16:9）でのプレイを想定しています」と明示している

## 9. AI 学習データについて

牌譜 6,389 局を AI の教師データに使う案は、**利用条件と作者の意向を先に確認**する。
今回のルール監査は「公開 API を読んで自分の実装と突き合わせる」なので性質が違う。
学習に使うのは別の話として分けて考える。

## 1. 牌譜の公開 URL

- `matches.is_public` [既定 0] を足した。**既定は非公開のまま**
- `GET /api/matches/public` … ログイン不要。`is_public=1` のものだけ返す
- `GET /api/matches/{id}/paifu` … `is_public=1` ならログイン不要で読める。それ以外は従来どおり 401
- `POST /api/matches/{id}/public` … 公開 / 非公開の切り替え [ログイン必須]
- 再生画面に「🔒 非公開 [公開する]」/「🌐 公開中 [やめる]」と「🔗 この局面のリンク」
- リンクは `?replay=<id>&round=&step=`。開くとメニューを飛ばして牌譜が直接開き、
  その局・その手数から始まる
- 未ログインで牌譜を開くと、自動で公開ぶんの一覧に落ちる

## 6. 自動抜き

- 画面設定の「自動抜き」が入っている時だけ、自分の手番で北が抜ける状態なら自動で抜く
- 抜くか切るかは 流し役満 を狙う時の判断なので**既定は off**
- 和了れる時 [`canTsumo`] は自動で抜かない。人に判断を渡す
- 自動ツモ切りと同じ scheduler に載せて、modal・演出・宣言待ちの間は出さない。
  自動抜きが動く局面では自動ツモ切りを譲る [抜いてから切る]

## 7 の代わりに入れたもの: ルール版数

ルールセットの編集 UI は入れていない [対局の中身を触るので、裁定を画面から変えられる形は
別の判断が要る]。代わりに、**牌譜にルール版数を焼き込む**ところだけ先に入れた。

- `ANMIKA_RULE_VERSION = 'anmika-1.0.0'` [`src/lib/prefs.ts`]。**裁定を変えたら上げる**
- 対局保存時に `rule_version` として送り、`matches.rule_version` に残す
- 再生画面に「ルール anmika-1.0.0」と出る

公開リンクを配れるようになった以上、あとからルールを変えた時に
「この牌譜はどのルールで打たれたのか」が分からなくなるのが一番困るため。
