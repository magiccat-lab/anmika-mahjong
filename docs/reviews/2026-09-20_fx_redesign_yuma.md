## 0. 結論 [先に読む]

- **ネタバレの経路は 2 本あった**。(1) 画面設定「山を見る」(09-14) が debug 用の山パネルをそのまま出し、生牌のツモ順・嶺上・裏ドラの牌面が対局中に見えていた → **直した** (191c9f2、伏せ牌と枚数だけ)。(2) フィーバー立直の「待ち情報」が待ち牌の残り枚数と赤・金・虹の有無を **山の現物** から数えている (見えている牌からの推定ではない)。これはルール上そういう物かもしれないので、裁定待ち (5 章)
- 演出は 6 種のカットイン (リーチ / ロン / ツモ / フィーバー / カン / ポン、黒帯 + 金文字 1.8 秒、全幅) と、白ぽっち開封モーダル (ダンガンロンパ風)、サイコロモーダル、フィーバーの白フラッシュ、結果パネル、スタンプ。処理落ち (0.5〜0.9 秒の固まり) は全部カットイン中に出ている
- **ゼロベースの原則は 7 つ** (2 章)。一言で「事実が先、演出は後。卓を隠さない。軽・中・重の 3 段」
- **案は 6 本** (3 章、絵は contact.png)。俺の推しは **B (牌が主役) を軸に、和了と役満だけ C (墨字判) の重さを足す**。理由: 文字の帯は何色にしても「ゲームっぽい」を抜けない。牌そのものと千点棒が動けば麻雀の所作に見える。B は DOM 3 個で済むので処理落ちにも効く
- 選んでもらったら実装は俺。共通の骨 (演出レイヤー、3 段の尺、タップでスキップ、online 同期) は案に依らず同じなので、絵の差し替えだけで案を変えられる作りにする (4 章)

## 2. ゼロベースの原則 [7 つ]

1. **事実が先、演出は後**。卓の変化 (牌が置かれる、横になる、開く) を先に見せ、演出はその 0.1〜0.2 秒後に出す。演出が事実を先に言わない。伏せ物 (山、他家の手牌、開封前の色) は演出にも出さない
2. **卓を隠さない**。全幅の帯と全画面フラッシュは使わない。演出は「宣言した席」か「牌そのもの」に付く。中央を使うのは和了と役満だけで、それも中央パネルと手牌は覆わない
3. **重さは 3 段**。軽 (リーチ / ポン / カン / 抜き: 0.6 秒以内、その場で) / 中 (ツモ / ロン: 1.2 秒以内) / 重 (役満 / フィーバー / ぽっち開封 / サイコロ: 2 秒以内、タップでスキップ)。今は全部 1.8 秒の同じ重さ
4. **色 1 つ、書体 1 つ**。差し色は金 (#d9b453) だけ。カン / ポンの青緑はやめる。文字は 1 書体 (案 C だけ筆文字)
5. **軽さの上限**。transform と opacity だけで動かす。blur / filter / mix-blend は禁止。1 演出 3 DOM 以内。レイアウトを動かさない (position: fixed の層 1 枚)。これが処理落ちの直し (堅牢性レビュー 2 章) と同じ話
6. **スキップと連結**。タップで即終了。連続する演出 (ポン → リーチ) は queue で隙間なく繋ぎ、入力を止めるのは 重 の間だけ
7. **online は同じ物を同じ時刻に**。演出は accepted action から起こす (今の cutin と同じ経路)。client 側の推測で出さない

## 3. 案 [6 本、絵は contact.png]

| 案 | 一言 | リーチ (軽) | ツモ (中) | 尺 | DOM | 向き不向き |
|---|---|---|---|---|---:|---|
| A 席札 | 宣言席の脇に漆の札 | 縦書き「立直」の札が席の横にせり上がる | 手牌の上に横札「自摸」+ 和了牌が浮く + 役 1 行 | 0.7 / 1.2 | 2 | 卓を隠さない。文字があるので分かりやすい。「札」の質感で差が出る |
| B 牌が主役 | 文字を使わない | 宣言牌が横になり金の輪が 1 回広がる、千点棒が中央へ滑る | 和了牌が手牌から浮いて 2 倍で見せ、小さく「ツ モ」 | 0.6 / 1.2 | 3 | 麻雀の所作に一番近い。一番軽い。文字が無いので初見は迷うかも (千点棒で分かる) |
| C 墨字判 | 朱印を押す | 「立直」の朱印が席の脇に斜めに押される | 大きい朱印「自摸」+ 和了牌が浮く | 0.8 / 1.2 | 2 | 一番「顔」がある。役満・フィーバーの 重 に向く。多用すると重い |
| D 一行テロップ | 上端 1 行 | 上端に「上家 リーチ」、直前 2 件が薄く残る | 「自分 ツモ 40符 3翻 5,200 オール」+ 和了牌が光る | 0.5 / 0.8 | 1 | 一番軽く、履歴になる (「今何が起きた?」に効く)。演出としては地味 |
| E 光の輪 | 席から輪 | 席の枠が光り、輪が 3 本広がる | 手牌から輪 + 小さく「ツ モ」 | 0.6 / 1.0 | 3 | 方向が一目で分かる。輪は transform だけ。文字が小さいので情報は D と併用したい |
| F 現行の圧縮版 | 今の帯を小さく | 帯を 1/3 の高さにして宣言席の側に寄せる | 手牌の上の帯 + 和了牌が光る | 1.0 | 2 | 変更最小。ただ「帯 + 文字」の骨は変わらないので、ダサさの根は残る |

俺の推し: **B を骨にして、和了 (ツモ / ロン) と 重 に C の朱印を足す** (B + C)。リーチ / ポン / カン は牌と千点棒だけ。役満・フィーバー・ぽっち開封は朱印。D のテロップは 演出ではなく 履歴 として上端に常設 (堅牢性レビューの「手番の残り秒」と同じ行に置ける)。

全案共通で入れる物: 和了は「牌 → 開示 → 演出」の順、タップでスキップ、カン / ポンは 軽、フィーバーの全画面フラッシュ廃止、音は 中 と 重 だけ (軽は無音か小さい 1 音)。

## 4. 実装の骨 [案に依らず同じ]

- `FxLayer.svelte` (新規、`CutinOverlay.svelte` の置き換え)。position: fixed の 1 層、案ごとの部品は子コンポーネント。`cutin` / `cutinQueue` の store 経路と App 側の pump / watchdog はそのまま使う (07-23 の排他制御と単一所有者を壊さない)
- `CutinPayload` に `tier: 'light' | 'mid' | 'heavy'` と `anchor` (席 / 牌の位置) を足す。尺は tier で決め、`CUTIN_DURATION_MS` 固定をやめる。watchdog の 3 倍尺も tier の尺から
- 事実が先: 和了時の enqueue を「手牌開示の後」に移す (store.ts の hule 経路 4 か所: 2777 / 796 / 1826 / 2036)。online は projection の開示と同じ tick で
- スキップ: FxLayer が pointer-events を持つのは 重 の間だけ。タップで `finishCutin(ts)` → `playNextCutin()`
- 白ぽっち開封と サイコロ は 重 の部品として同じ層に載せ替える (別モーダルをやめる)。開封の「?」→ 色 の流れは残す
- 処理落ち: この置き換えで cutin 中の DOM 更新が減るが、本命の「store 更新で App.svelte 全体が再評価される」は別 (堅牢性レビュー 2.3)。演出を軽くした後に計器 (`tools/perf_probe_solo.mjs`) で before/after を取る
- テスト: 演出の enqueue 順 (牌 → 演出) を store のテストで、スキップと queue 連結を `tests/` の e2e で、見た目は `screenshot_audit` の before/after

手間: B + C で 2 日 (骨 1 日、絵 1 日)。他の案も同じ骨なので差し替えは半日。

## 5. リョーに決めてもらう事

1. **案**: A〜F のどれか、または組み合わせ (俺の推しは B + C)
2. **フィーバー待ち情報の残り枚数**: 山の現物から数える今のまま (ルールとしてそういう物) か、見えている牌からの推定に変えるか。変えるなら「残り」の意味が「見えていない枚数」になる
3. **「山を見る」の対局中の扱い**: 伏せ牌と枚数だけにした。牌譜再生と観戦では牌面のまま。それでいいか
4. **音**: カットインに音を付けるか (今はぽっちとサイコロだけ)。付けるなら 中 と 重 だけ
5. **ぽっち開封の尺**: CPU 番も人間と同じ 0.8 秒 + 手動閉じか、CPU 番は自動で短くするか
